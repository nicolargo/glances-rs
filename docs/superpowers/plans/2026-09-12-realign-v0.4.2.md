# v0.4.2 realignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Realign glances-rs with the three stable/additive changes in Glances `develop-v5` (v5-rewrite stack) found by the 2026-09 audit: missing `short_name`s, the generic per-item `hidden` flag on network/diskio, and the `/api/5/all/info` route.

**Architecture:** Additive only. No change to any existing field value, no change to default behaviour. `hidden` is always `false` (glances-rs has no value-based hide mechanism; it filters by name/regex, removing items). `short_name` is `/info`-only. `/all/info` reuses the existing `/info` field-schema builder.

**Tech Stack:** Rust 2024, axum 0.8, serde_json, tokio current_thread. No new dependency.

## Global Constraints

- **Config-only alerting stays (Gap 3 decided = keep config-only).** Do NOT add built-in `default_thresholds`. This is why the `/{plugin}/limits` and `/all/limits` routes are deliberately OUT of scope (their Glances semantics = default+config merged, which glances-rs can't match without built-in defaults).
- **No default-behaviour change.** `hidden` is always `false`; `short_name` affects `/info` only; `/all/info` is a new read-only route. Existing payloads for existing fields stay byte-identical.
- **Source of truth:** Glances v5-rewrite modules (`glances/plugins/<p>/model_v5.py`, `glances/plugins/plugin/base_v5.py`) in the local `/home/nicolargo/dev/glances` checkout at `origin/develop-v5`. The repo is alpha and may lag the maintainer's live server — values below are from the repo; flag them for live-server spot-check at review.
- **Inert `/all/info`:** like `/info` and `/alert` — no wake, no store read, no `503`. Reuses the field-schema serialization from `plugin_info`.
- **Footprint mandate:** additive `&'static` table entries + one new inert route; no hot-path change. No footprint audit needed (note "unchanged, additive" in docs).
- Run `cargo fmt --all` before every commit; `make lint` (clippy `-D warnings`) + `make test` gate each task. `Cargo.lock` in sync.

```rust
/// `GET /api/5/all/info` — every registered plugin's field schema at once,
/// keyed by plugin name (the `/all` analogue of `/{plugin}/info`). Inert:
/// static metadata + config only, never wakes a collector.
async fn all_info(State(app): State<Arc<AppState>>) -> Json<Value> {
    let mut out = Map::new();
    for id in PluginId::ALL {
        if !app.is_registered(id) {
            continue;
        }
        let mut fields_obj = Map::new();
        for fi in fields(id) {
            fields_obj.insert(fi.field.to_owned(), field_schema(&app, id, fi));
        }
        out.insert(id.as_str().to_owned(), Value::Object(fields_obj));
    }
    Json(Value::Object(out))
}
```
(If `field_schema`/`fields`/`Map`/`Json`/`Value` are not already imported in scope, they are — `plugin_info` uses them. Confirm `field_schema`'s signature matches this call; if it is private in the same module, it is directly callable.)
